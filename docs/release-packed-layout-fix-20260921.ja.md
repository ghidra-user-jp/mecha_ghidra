# 自動配置される構造体の修正と検証（2026-09-21）

[リリース前レビュー](release-packed-layout-review-20260921.ja.md)で確認した、`add_struct_members` が明示offsetを守らない問題を修正しました。

## 変更内容

明示offsetを指定したメンバーの編集時に、自動配置（packing）が有効なら、公開APIの `setPackingEnabled(false)` で既存の位置を固定してから拡張・置換します。変更対象外のフィールド位置を維持しながら、末尾・末尾以降への追加も可能になります。

たとえば `struct Packet { char tag; int value; char tail; };` に対してoffset 4の `value` をcharの `extra` に置き換えると、修正前は `extra=1, tail=2, length=3` になっていました。修正後は **`extra=4, tail=8, length=12`** となり、保存・再読み込み後も維持されます。

- offset省略時は、その時点の配置方式で末尾へ追加します。自動配置が有効な型は、明示offsetを指定するまで自動配置を維持します。
- 同じ呼び出しでoffset指定あり・なしを混ぜた場合も、入力順に編集します。
- 自動配置の解除は既存の編集トランザクション内で行います。後続の不正offsetや領域不足で失敗した場合、追加済みフィールドと構造体長だけでなく、自動配置設定も元に戻ります。
- ツール説明と日英のツール文書に、明示offsetが自動配置を解除することを記載しました。短縮モードの説明は173文字で、180文字の上限内です。

非推奨APIや外部ライブラリの非公開APIへのパッチは追加していません。
