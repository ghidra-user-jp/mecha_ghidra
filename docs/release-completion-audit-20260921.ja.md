## 配布物

現ソースのコピーから `uv build --offline` で `ghidra_mcp-1.0.0.tar.gz` と `ghidra_mcp-1.0.0-py3-none-any.whl` を作成しました。wheel・sdist双方のPython **109モジュール** が現ソースとバイト単位で一致し、バージョンとApache-2.0のライセンス情報も一致しています。
